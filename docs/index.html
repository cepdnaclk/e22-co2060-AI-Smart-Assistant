Key Technical Features

Local AI Inference

Powered by Mistral via Ollama for zero-latency, offline text streaming.

High-Speed OCR

Tesseract and Pillow (PIL) preprocessing for accurate screen text extraction.

Intelligent Caching

Custom JSON NoSQL with fuzzy-matching for instant recurring error resolution.

Async Architecture

Python multiprocessing prevents UI freezing during heavy AI generation.

System Architecture

Upload your architecture diagram here (assets/architecture.png)

Our architecture is built on a robust Python multiprocessing foundation. It utilizes an isolated background orchestrator to monitor global hotkeys and capture specific screen regions. The image undergoes contrast enhancement via Pillow before Tesseract OCR processing. Extracted text is routed through a fuzzy-matching sequence algorithm against our JSON NoSQL cache. On cache misses, the query is sent to the local Ollama API, streaming the Mistral LLM's response back to the main frontend asynchronously via IPC Queues.
