Project Overview

Addressing limitations in traditional robotic process automation.

warning

The Problem

Traditional automation tools rely on rigid selectors or coordinate-based scripting. They lack "vision" and cannot understand dynamic UI changes, requiring constant maintenance and breaking easily with minor UI updates.

check_circle

The Solution

A semantic understanding layer combining OCR for text extraction and LLMs for reasoning. The system "sees" the screen like a human, interpreting intent and executing actions through simulated input events dynamically.

System Architecture

1. Input Acquisition

Captures active window state and user voice/text commands.

2. Semantic Analysis

Tesseract OCR extracts text; LLM creates a structured representation of the UI.

3. Planning

The reasoning engine decomposes the goal into a sequence of atomic actions.

4. Execution

PyAutoGUI triggers OS-level events to manipulate the interface.
